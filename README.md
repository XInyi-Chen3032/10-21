# Global Superstore Sales Dashboard
## 1. Who is this dashboard for & what decision it supports
This dashboard is built for a retail sales manager of the global superstore. It supports reviewing order records, filtering sales by region and product category, inspecting high-value sales and analyzing sub-category sales performance.

## 2. What visualizations I chose to show, and why
I use sidebar multi-select filters, an interactive dataframe table and a bar chart. The dataframe lets the manager sort and check raw order details. The bar chart summarizes total sales across sub-categories quickly. These are simple and directly support sales review.

## 3. Charts or features I cut out and why
I removed map plots, profit charts and extra KPIs. Adding more charts makes the app heavier and slower. Since the core requirement is filtering and viewing order data, unnecessary visuals are removed to keep the dashboard stable.

## 4. Recommended refresh frequency and justification
Monthly refresh is recommended. This is historical sales transaction data, which does not change daily. A monthly update balances data usefulness and computation cost.
